# 左手摄像头控制（Stage E）

## 当前实现与验证

右手 IMU 控制节奏与挥拍强度；摄像头仅用确认后的生理左手控制音量和暂停/恢复。已实现摄像头操作、镜像预览与关键点显示、左手确认、手动/左手音量来源、手势开关、左手丢失处理及资源清理。固件和 Conda 环境沿用上一阶段。

当前 52 项 Node 测试和 Vite 生产构建通过。此前用户在真实 Chrome 运行视觉诊断页，2 项检查通过：本地模型和 WASM 在 classic Worker 中加载约 379 ms，两个空白图像的识别约 95/22 ms。结果保存到 `recordings/vision-runtime-20261005.json`。诊断页未启用摄像头，也未播放声音；这些结果不代表实际手部识别准确率或帧率。

2026-10-10 用户已确认实际摄像头开启、左手确认/追踪、左手高度对应的音量数值与听感正常。对齐 Lab4 后张掌恢复仍不稳定；根据后续分数记录调整张掌规则后，用户完成 3 轮人工复测，反馈 3 次暂停、3 次恢复均成功且位置连续。该轮已刷新页面，未导出操作 CSV，故位置连续按用户反馈记录，不声称已核对精确 tick。双手隔离、主动丢失及重开待确认。涉及用户的测试必须先汇报目的和动作，然后停下，等待用户明确说“开始测试”后再执行。

## 使用方式

1. 主页面点击“开启摄像头”，在 Chrome 中允许摄像头访问。该操作独立于 Arduino，不需要先连接 COM3。
2. 只举起左手，右手暂时离开画面。模型连续稳定识别一只手至少 700 ms 后，“确认左手”可用；用户确认当前举的是生理左手后点击。
3. 将音量来源改为“左手高度”。左手掌中心越高越响，越低越轻。画面高度约 20% 对应 -3 dB，约 80% 对应 -30 dB，超出范围保持边界值。左手位置使用约 220 ms 的时间平滑。
4. 点击“播放音乐”启用声音。左手握拳沿用 Lab4 的 0.65 阈值和连续 3 次确认；张掌使用 0.55 阈值和连续 5 次确认，以接受本次记录的自然张掌分数，同时增加确认次数。持续同一手势只执行一次，停止状态不会由张掌自动开始播放。可关闭播放手势，单独测试音量。
5. 音乐暂停期间保留音量。左手丢失、选择不确定、识别置信度不足时也保留音量，清除未完成的手势计时；丢失超过 500 ms 显示左手丢失，音乐不自动暂停。仅剩右手时同样按左手丢失处理。
6. 切回手动音量时恢复此前保存的滑块值。关闭摄像头、离开页面或开发热更新会停止轨道并终止识别 Worker；重新开启需再次确认左手。
7. 导出拍点记录时，同时保存 `HOST_VISION` 的摄像头、左手确认、追踪状态、音量来源、原始手势读数变化和手势操作事件，以及 `HOST_MUSIC` 的实际音乐操作。视频图像与逐帧关键点不写入 CSV。

## 模块与约束

- `vision.js` 管理摄像头启动/取消/停止，传送 ImageBitmap，释放轨道和 Worker。每次只允许一帧在处理，最多约 20 FPS，重复视频帧跳过，超过 250 ms 的过期结果不用于控制。
- `public/mediapipe/vision-worker.js` 使用 CPU 模型推理；classic Worker 可直接运行当前 MediaPipe 1.0.1 的 `importScripts` WASM 加载流程。IIFE、WASM 和模型均来自本仓库本地资源。`npm run dev` 与 `npm run build` 均同步锁定版本运行资源。
- `hand-control.js` 处理确认、左右标签、同索引结果选择、手掌位置平滑、连续手势与丢失。模型检测上限为两只手，只有已确认的左手标签进入控制。左右置信度阈值为 0.7，仅保留 `Open_Palm`/`Closed_Fist`。握拳 0.65 / 连续 3 次，张掌 0.55 / 连续 5 次；重复或倒退时间戳不增加计数，低置信度、丢失和过长帧间隔清除候选。调试区显示原始分类与分数，CSV 的 `GESTURE_READING` 保存类别/接受状态变化及限频的分数变化，并包含实际阈值和所需次数。
- “复制调试信息”在点击时固定快照，尝试写入剪贴板；浏览器拒绝剪贴板时仍可从只读文本框复制。实时刷新不修改该文本框。手势关闭时控制确认进度清零，原始分类与分数仍可查看。
- 左手确认保存实际左手在当前输入管线中的模型标签，不使用画面左半边或结果数组第一项推断生理左手。确认时必须仅举左手；手别模型仍可能误分类，需要实机验证双手同时出现、交叉和右手单独出现。
- 手势调用现有 MusicSession 的暂停/恢复，沿用音乐位置与静音处理；右手 IMU 和音量控制彼此独立。音量更新至少间隔 100 ms、变化至少 0.25 dB，以减少无意义的重复排程与日志。
